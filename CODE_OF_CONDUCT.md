# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository, its issues, pull requests and discussions, and anywhere you represent the project.

In short:

- Be respectful. Disagree with ideas, not with people.
- No harassment, insults, sexual language or imagery, or personal attacks.
- Don't publish other people's private information.
- Maintainers may remove comments, commits, code and issues that break these rules, and may ban people who break
  them.

## Reporting

Report unacceptable behaviour in an issue, a pull request or a comment with GitHub's Report content (its … menu). To
reach the maintainers privately, open a private report on this repository (Security › Report a vulnerability) and say
in its title that it is about conduct. Reports are kept confidential. The Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
decide the response.
